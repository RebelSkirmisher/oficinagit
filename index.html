Comandos GIT

  • git init - inicializa um novo repositório git [out - git clone - para clonar um repositório remoto]
  • git add nomeArquivo - adiciona um arquivo novo no stage
  • git status - mostra o estado do diretório
  • git log [--oneline] exibe log dos commits da branch
  • git commit - commita as mudanças para a branch selecionada
  • git checkout [-b] nome-branch - troca de branch
  • git merge nome-branch - mergea uma branch com a atual, trazendo as mudanças dela para a atual
  • git branch [-d] [nome-branch] - lista de branches, criar uma ou deletar
  • git remote add origin url.com - adiciona uma origem remota para guardar o repositório
  • git push -u origin main - pusha as mudanças locais da main para o repositório remoto
